GPGPU Particle System

65k+ particle positions stored in a texture — physics computed by a fragment shader each frame (texture ping-pong).

GPGPU = compute on GPU. Particle data lives in textures — each RGBA32F pixel is one particle's (x, y, vx, vy). A physics shader writes new positions every frame without touching the CPU.
