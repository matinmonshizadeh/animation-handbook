ASCII / Halftone

A moving picture is redrawn with letters or dots. Best for retro and tech looks.

1

Watch it

It moves by itself. Pause it to look closely at the letters, or turn on slow motion.

2

Try it

Change a setting and see the difference as it moves.

Drawn with

Brighter spots get letters with more ink, or bigger dots.

Detail

Smaller letters or dots show more of the picture; phones use bigger ones.

Colors

One color looks like an old screen; full color keeps the picture's colors.

More optionsFewer options

Lays the moving picture faintly under the letters or dots.

Prints dark marks on light paper, like a newspaper photo.

3

Copy the prompt

Paste it into an AI assistant such as ChatGPT, Claude or Cursor to build this in your own project.

Add an ASCII and halftone effect to [the picture or video you want to restyle]. Each frame, draw the picture onto a small hidden canvas with one pixel for every cell of a grid, and read back each pixel's brightness. On the visible canvas, draw a character in every cell, choosing characters with more ink for brighter cells, or draw a dot whose size grows with the brightness, like a printed photo. Color the marks with the picture's own colors or with one color. Copy the characters from a ready-made sheet instead of typing each one, so it stays smooth, and use bigger cells on phones. If the visitor has reduced motion turned on, show one still frame. Match the settings listed below.
