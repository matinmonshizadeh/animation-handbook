Matrix Rain

Columns of glowing characters fall down a dark canvas — bright leaders, fading trails.

— fps

Each column drops one bright character per step. A translucent black rectangle painted every frame fades old characters into the trail — never cleared, so the tail length is a function of the fade opacity.
