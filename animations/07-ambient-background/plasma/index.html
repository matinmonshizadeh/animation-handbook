Plasma Field

Smooth waves of color flow endlessly, made from math. Best for creative sites.

1

It moves by itself. Pause it to look closely, or turn on slow motion to see each part of the movement.

One wave

Four waves

Inside, the colors come from four simple waves added together: the gray tiles show each one alone. At every spot their total picks a color from the strip.

On the left, One wave is a single wave, so it makes plain stripes. On the right, Four waves adds up waves running four ways, so the colors blend into soft blobs.

Copy the prompt

Paste it into an AI assistant such as ChatGPT, Claude or Cursor to build this in your own project.

Add a plasma background to [the section you want it behind]. For every point, add up a few waves based on its position and on time (across, down, diagonally and outward from the center) and use the sum to pick a color from a smooth palette, so the whole field flows like liquid color. To keep it fast, draw the field into a small image and scale it up smoothly to fill the section, using a smaller image on phones. If the visitor has reduced motion turned on, show one still frame.
