Topographic Lines

Contour lines like those on a hiking map slowly bend and drift. Best for outdoor brands.

1

Watch it

It moves by itself. Pause it to look closely, or turn on slow motion to see each part of the movement.

2

Try it

Change a setting and see the difference as it moves.

Line spacing

How much the height changes from one line to the next.

Speed

How fast the hills swell and drift.

Color

The color of the lines.

More optionsFewer options

Hill size

Small hills make busy rings; large ones make long, lazy curves.

Every fifth line is drawn thicker, as on a printed map.

3

Copy the prompt

Paste it into an AI assistant such as ChatGPT, Claude or Cursor to build this in your own project.

Add a topographic lines background to [the section you want it behind]. Build a smooth, hilly height map from layered noise and draw its contour lines on a canvas: sample the height on a grid, and in each grid square join the points where the height crosses each level, so every line follows one height, as on a hiking map. Make every fifth line bolder when the settings include it. Shift the noise slowly by elapsed time so the hills swell, shrink and drift, and redraw each frame. Sample a coarser grid on phones. If the visitor has reduced motion turned on, show the lines still. Match the settings listed below.
