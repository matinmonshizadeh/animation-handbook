Grid / Dot Pattern Parallax

Subtle background pattern translates opposite to mouse movement — imperceptible depth, very effective.

Dot Grid Parallax
Move your mouse across the stage
The pattern shifts slightly opposite to your cursor — a depth illusion so subtle you almost don't notice it.

Keep parallax under 10% of cursor movement. Higher values look like wallpaper sliding. Linear's marketing site uses this pattern beautifully.
