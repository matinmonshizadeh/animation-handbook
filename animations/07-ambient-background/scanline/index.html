Scanline Effect

Repeating dark lines over content create a CRT monitor aesthetic — optional sweep beam and phosphor glow.

$ initialize_system --mode ambient
// scanning for motion patterns
→ all systems nominal
→ rendering 60fps continuous
_

Scanlines = nostalgic. Static + sweep beam = cinematic sci-fi. Add curvature + phosphor = full CRT simulation. Use sparingly — the look is dated by design.
