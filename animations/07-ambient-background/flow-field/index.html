Flow Field

Particles ride a vector field sampled from inline pseudo-noise, leaving fading trails that map the invisible currents.

— fps

There is no image here — only a math function that returns an angle for every point on screen. Each particle reads the angle under it and steps that way. Trails appear because the frame is dimmed, not cleared.
