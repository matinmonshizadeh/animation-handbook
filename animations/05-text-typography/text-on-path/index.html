Text on a Path

Text travels along a wave, an arc or a circle. Best for badges and seals.

1

It moves by itself. Pause it to look closely, or turn on slow motion to see each part of the movement.

On a path The text is attached to this curve Each tick starts one copy of the phrase Letters show only between the dots Slides a quarter of the curve a second

Inside, the text is attached to a curve, drawn bold here. The phrase is repeated, and each tick marks where one copy starts; they all slide along the curve together.

Straight line slides the same words along a flat line, like a ticker. On a path bends them around the curve, so every letter follows its shape.

Copy the prompt

Paste it into an AI assistant such as ChatGPT, Claude or Cursor to build this in your own project.

Add text that travels along a curve to [your short phrase]. Define the curve once and attach the text to it so every letter sits on the line, then keep moving the point where the text starts so the letters travel along the curve like a ticker bent into shape. Repeat the phrase, with a separator such as a dot, until it covers the whole curve, and wrap around by exactly one copy so the loop has no jump. Keep the curve gentle enough that letters do not crowd on sharp bends. If the visitor has reduced motion turned on, show the text still on the curve. Match the settings listed below.
