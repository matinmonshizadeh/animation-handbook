Wavy Text

Each letter is its own span with a staggered animation-delay, so a vertical sine wave travels across the word.

Wavy

JS splits the string into per-letter spans and sets a --i index on each. A shared bob keyframe plus a delay of i × stagger phases neighbours apart, producing a rolling wave.
