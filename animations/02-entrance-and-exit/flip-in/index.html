Flip In

Rotates from a flat plane into view using CSS 3D perspective — perspective on the parent is the key.

⬡
3D Flip
Perspective is set on the parent, not the card. Without it, rotateY looks like a horizontal squash — not a 3D rotation.

Flip-in requires `perspective` on the PARENT element, not the flipping card. The perspective value sets the viewer distance — lower = more dramatic, higher = more subtle.
