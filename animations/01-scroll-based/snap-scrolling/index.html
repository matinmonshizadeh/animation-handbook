Snap Scrolling

Page snaps to defined sections — CSS scroll-snap-type creates a deliberate paginated feel.

Snap scrolling is native CSS — three lines and zero JavaScript do the magnetism. 'mandatory' forces a snap on every scroll. 'proximity' only snaps when close to a point. 'none' disables it. Switch modes and feel the difference.
