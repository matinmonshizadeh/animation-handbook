Render Pipeline

Compositor-only properties (transform, opacity) bypass layout and paint entirely. Animating height forces layout on every frame — the production alternative is clip-path or scaleY on a fixed-height container.

"The fastest animation is one the compositor runs without consulting the main thread."

Single-Progress Model

One value p ∈ [0, 1] drives all eight properties simultaneously. When everything shares the same source of truth, every intermediate scroll position has a consistent, intentional appearance.

Easing p once (easeOutCubic) rather than each property separately keeps multi-property deceleration coherent. Use the transition range slider to feel how the same logic produces very different pacing.

This pattern is the foundation of every good article header on the modern web — Medium, Substack, NYT, Stripe blog. The trick is scrubbing every property to a single 0→1 progress value so intermediate states all look intentional.
