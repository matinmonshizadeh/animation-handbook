SVG Line Draw on Scroll

A long winding route embedded in the page draws itself as you scroll down it, popping waypoints as the line reaches them.

— end of route —

The path is part of the page, not a pinned scene. stroke-dasharray is set to the path's length once; each scroll frame writes stroke-dashoffset = length − drawn, revealing exactly as much of the route as you have travelled.
