Section Wipe

Stacked sticky sections with ascending z-index — the next section rises over the current one as you scroll.

01
Position, Not JavaScript
Section wipe is entirely structural. Each section is sticky at top:0. The next section has a higher z-index and rises naturally as the user scrolls past the first section's height. No animation code for the wipe itself.
02
The Receding Layer
The only JavaScript-driven effect is the scale-down on the section being covered. As section 3 rises over this one, scale compresses from 1.0 toward the scale floor — making it feel like it's sliding behind the incoming section.
03
Scrubbed Coverage
The scale animates proportionally to how much of the viewport the next section has covered. Mid-scroll, the transition is frozen at an intermediate value — no snap, no jump. Drag the scroll bar slowly to inspect the overlap.
04
Final Section
This section never recedes — it's the topmost layer. GSAP ScrollTrigger can implement this same pattern with scrub:true on a scale tween, adding the ease that CSS alone can't provide here.
