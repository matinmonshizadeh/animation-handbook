Smooth (Inertia) Scroll

Wheel and touch input drive a target value; the content eases toward it each frame for a weighted, gliding feel.

drag or scroll ↑↓

Native scroll snaps to the input instantly. Smooth scroll keeps a target and a current value, then lerps current toward target every frame: current += (target − current) × ease.

Ease / lerp factor
ease0.09
lower = heavier glide
