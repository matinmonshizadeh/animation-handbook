Sticky Section

The whole section pins to the viewport while its interior morphs through 4 states — scrubbed to scroll position.

Scroll down to enter the sticky section ↓
State 01 · Foundation
Everything starts with structure.
Before any animation, there is layout. CSS sticky positioning transforms a single section into an extended viewport experience without JavaScript pinning.
State 02 · Transition
Scroll becomes the timeline.
Progress through the sticky section is computed as a 0–1 value. Each state occupies 25% of that range. State boundaries are thresholds, not events.
State 03 · Interpolation
Between states, values blend.
Crossfades between opacity values, illustration swaps, and text transitions happen in the fractional space between integer state indices — smooth, not stepped.
State 04 · Release
When the budget runs out, scroll continues.
The sticky wrapper ends and the section scrolls away. Content after it resumes normal flow. The pin is defined entirely by the wrapper's height.
