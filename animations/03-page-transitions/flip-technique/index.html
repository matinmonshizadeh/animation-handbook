FLIP Technique

First-Last-Invert-Play — CSS layout changes animated seamlessly by measuring position deltas.

FLIP solves layout animation: 1. Record First positions. 2. Apply new layout (cards jump instantly). 3. Invert — apply a transform that puts each card back visually at its original spot. 4. Play the transform to zero so cards glide to their real positions.
