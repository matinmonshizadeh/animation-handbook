Error Shake

Invalid input triggers a decaying horizontal wobble plus a red border — a universal "no".

Sign in

Password is letmein. Try a wrong value (or submit empty) to see the shake.

A shake decays — big swings settle to small ones, then stop. That deceleration reads as a headshake: motion that returns to origin says "denied," not "progress."
