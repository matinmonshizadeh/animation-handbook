Height animates between 0 and auto — two approaches: JS measured height and CSS grid-template-rows.

FLIP stands for First-Last-Invert-Play. It's a technique for animating layout changes smoothly by recording positions before and after a DOM change, then playing the inverse transform away.

max-height animation requires a fixed maximum value (e.g. 1000px). If the content is shorter, the easing is wrong — it runs through "empty space" first, making the timing feel off.

Set grid-template-rows: 0fr on the container, with the inner div having overflow:hidden and min-height:0. Animating to 1fr reveals the content. No JS needed, but requires 2023+ browser support.

FAQ sections, settings panels, navigation menus, and long-form content where hierarchy matters. Avoid using them when all content should be visible simultaneously — use tabs or sections instead.

Also avoid deeply nested accordions — more than two levels confuses navigation.

Use button elements for triggers (keyboard focusable by default). Toggle aria-expanded on the trigger. Link trigger to content with aria-controls / role="region". Screen readers announce open/closed state from aria-expanded.

animating height to auto doesn't work in CSS natively. JS measures scrollHeight; CSS grid-template-rows: 0fr→1fr avoids JS but requires modern browsers.
