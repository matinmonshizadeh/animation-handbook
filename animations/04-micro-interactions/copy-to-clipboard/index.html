Copy to Clipboard

A copy button morphs to a checkmark and "Copied!" on success, then reverts after a short delay.

snippet.jsclick copy to grab it
const el = document.querySelector('.card');
el.animate(
  [{ opacity: 0 }, { opacity: 1 }],
  { duration: 300, easing: 'ease-out' }
);
Uses navigator.clipboard.writeText with a document.execCommand fallback.

Success feedback should be transient: confirm the action, then quietly revert so the control is ready to use again.

Revert delay
1500ms
Animation duration
280ms
Easing

The checkmark and label share one .copied class toggle; a timer removes it to revert.
