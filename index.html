Animation Atlas

A visual reference of web animation techniques.

01 — Scroll-Based

  • Parallax Depth-of-Field Five mountain layers with parallax translation and blur-based depth-of-field driven by scroll.
  • Parallax Scrolling Four SVG layers at different scroll speeds create a 3D depth illusion; adjustable speed sliders show how ratios make or break the effect.
  • Reverse-Scrolling Columns A center column scrolls normally while two flanking columns scroll in reverse, looping infinitely — the opposing motion creates strong directional depth contrast.
  • Cover Card to Fixed Header A hero cover card scrubs into a compact fixed header on scroll — height, font size, opacity, and blur all driven by a single eased progress value.
  • Fly-in Fly-out Contact List Contact rows translate and fade through entry, active, and exit zones as you scroll — a continuous bidirectional effect scrubbed to scroll position.
  • Stacking Cards Cards stack as they overlap — position: sticky handles the layering, scroll drives depth cues via scale and brightness.
  • ScrollTrigger Animation The onEnter / onLeave lifecycle demonstrated with vanilla JS — four zones showing fade-on-enter, scrub, pin+scrub, and snap.
  • Scrub Animation A camera lens disassembles in five stages as you scroll — every transform welded to scroll position, no autoplay.
  • Pin Animation A phone mockup pins to the viewport while four features swap in sequence — CSS position: sticky, no JavaScript pinning.
  • Snap Scrolling CSS scroll-snap-type creates a paginated, magnetic feel — switch between mandatory, proximity, and none to feel the difference.
