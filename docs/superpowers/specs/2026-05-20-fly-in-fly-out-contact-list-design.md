## Overview

A scrollable contact list where each row flies in from below (fade + translate + scale) as it enters the viewport and flies out upward as it exits. The effect is continuous and bidirectional — scrubbed to scroll position, not a one-time reveal. An IntersectionObserver limits transform updates to only the rows currently near the viewport.

## Zone Math

For each tracked row, computed in the rAF callback:

```js
const viewportH = stage.clientHeight;
const pos = (row.offsetTop - stage.scrollTop) / viewportH;
// pos = 0: row top at viewport top
// pos = 1: row top at viewport bottom
// pos < 0: row has scrolled off the top
```

Three zones (Z = zone size, default 0.25):

| Zone | Condition | t formula | opacity | translateY | scale |
|------|-----------|-----------|---------|------------|-------|
| Exit (top) | pos < Z | `t = pos / Z` | `lerp(0, 1, t)` | `lerp(-DIST, 0, t)` | `lerp(SCALE, 1, t)` |
| Active | Z ≤ pos ≤ 1−Z | — | 1 | 0 | 1 |
| Entry (bottom) | pos > 1−Z | `t = (1 − pos) / Z` | `lerp(0, 1, t)` | `lerp(DIST, 0, t)` | `lerp(SCALE, 1, t)` |

Rows where `pos < −rowHeight/viewportH` (fully above) or `pos > 1` (fully below): not tracked by IntersectionObserver, keep last computed transform frozen.

## IntersectionObserver

```js
const io = new IntersectionObserver(entries => {
  entries.forEach(e => {
    if (e.isIntersecting) visible.add(e.target);
    else visible.delete(e.target);
  });
}, { root: stage, rootMargin: '25% 0px', threshold: 0 });

rows.forEach(row => io.observe(row));
```

`visible` is a `Set<HTMLElement>`. The rAF callback only iterates `visible`, not all 15 rows.

## Effect Mode Toggle

Three-way toggle (radio buttons or segmented control):
- **All combined** (default): opacity + translateY + scale
- **Translate only**: opacity always 1, scale always 1
- **Fade only**: translateY always 0, scale always 1

Under `prefers-reduced-motion`: force "fade only" mode with range `opacity 0.3 → 1` (no translate, no scale).

- Row `min-height: 56px` always (touch target)
- Sliders: `min-height: 44px`
- `clamp()` on header typography
- Touch scroll drives the effect (passive scroll listener on `.stage`)
- `prefers-reduced-motion`: fade only, opacity 0.3→1 at edges

## Performance

- `will-change: transform, opacity` on `.row`
- IntersectionObserver `root: stage, rootMargin: '25% 0px'`
- `visible` Set: only iterated rows in rAF callback
- `motionMQ.matches` re-read live in the rAF callback
- No layout reads inside rAF beyond `stage.scrollTop` (which is cached once per frame)
