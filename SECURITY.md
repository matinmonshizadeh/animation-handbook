# Security policy

Animation Handbook is a static website: HTML, CSS and JavaScript files that GitHub Pages serves as they are. It has no
server code, no accounts, no sign-up, nothing that collects what visitors type and no stored data of its own. The only
version looked after is the one on the `main` branch, which is the live site at
https://matinmonshizadeh.github.io/animation-handbook/.

## What to report

- A page that could run someone else's script, for example through words it puts on the page, a link it builds or an
  address it reads.
- A link, a request or a page that sends a visitor's data to another site.
- Something in the repository that should not be public, such as a key, a password or a private address.

A demo that looks wrong, runs slowly or breaks on some device is a bug, not a security problem: please open a
[bug report](https://github.com/matinmonshizadeh/animation-handbook/issues/new?template=bug_report.yml) for it.

## How to report it

Please do not open a public issue, pull request or discussion for a security problem. Report it privately instead:

- with GitHub's private vulnerability reporting:
  [report a vulnerability](https://github.com/matinmonshizadeh/animation-handbook/security/advisories/new), or
- by writing to [CONTACT].

Say which page or file it is, what can happen and how to make it happen. You will get an answer as soon as possible,
and another when it is fixed.
